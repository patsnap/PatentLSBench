# 评价协议

[LSBench](https://github.com/patsnap/LSBench#简体中文) · [English](evaluation-protocol.md) | **简体中文**

LSBench 从五项生命科学任务评价 AI 模型与 Agent 的专业交付。各任务具有各自的评价对象、匹配标准与指标。

## 任务与指标

| 任务 | 评价对象 | 指标 |
|---|---|---|
| [Chemical NER](../chemical-ner/README.zh.md) | 从完整专利文本中抽取的化学名称与分子结构集合 | 专利级集合精确率、召回率与 F1；名称与结构分别报告 |
| [Chemical OCSR](../chemical-ocsr/README.zh.md) | 从预裁图中识别的完整分子结构 | 按来源页分组的一对一结构匹配精确率、召回率与 F1；保留重复结构的出现次数 |
| [SAR](../sar/README.zh.md) | 已披露活性记录及其与结构、实验和来源位置的关联 | 记录对齐、字段级精确率、召回率与 F1，以及关系质量 |
| [LCA](../lca/README.zh.md) | 从专利号获取候选证据，或从药物代号追溯专利与候选分子 | 专利相关性、已知目标结构命中与证据支持；两种输入模式分别报告 |
| [Hiro LS Research](../hiro-ls-research/README.zh.md) | 包含来源引用的完整研究回答或报告 | 要点覆盖、事实质量与引用支持 |

Chemical NER 评价文本抽取。Chemical OCSR 评价预裁结构图的识别，整页检测与切分属于独立任务。SAR 评价已披露实验证据。LCA 评价候选识别与基于证据的追溯。Hiro LS Research 评价完整回答及其支持来源。

## 匹配与证据

- **Chemical NER：**同一专利中重复出现的相同结构在结构集合中计为一项。对不含分子结构的参考标注，采用名称匹配回退。名称匹配与结构匹配分别评价。
- **Chemical OCSR：**按来源页分组，对预测结构与参考结构进行一对一匹配。结构身份包含原子连接关系、键信息与立体化学信息。相同结构的重复出现仍分别计次。
- **SAR：**按化合物与实验条件对齐预测记录与参考记录。字段评价包括化合物编号、实验指标、数值、单位、实验模型、靶点、方法、结构身份、活性来源位置与结构来源位置。关系评价保留化合物、实验、测量与证据之间的对应关系。
- **LCA：**按适用输入模式评价专利相关性、完整结构身份、活性证据、来源位置与证据等级。证据等级表示验证深度。已知目标命中指标适用于具有已披露参考结构的子集，不代表完整召回。
- **Hiro LS Research：**评价回答是否回应研究问题、涵盖必要发现、准确陈述事实，并引用支持相应事实陈述的来源。

## 同条件评价

比较采用相同的任务材料、证据范围、信息截止时点、可用工具与执行预算。模型与 Agent 提交在各自组别内报告。报告明确被评系统、任务与参考版本、匹配或评分量规标准，以及适用的运行条件。

各任务分别报告评价单位、指标、覆盖范围与局限。专利、图像、结构、记录与问题的计数保持区分。NER 的名称与结构分别报告；LCA 的专利号模式与药物代号模式分别报告。LSBench 不将不同任务单位合成为单一总分。
