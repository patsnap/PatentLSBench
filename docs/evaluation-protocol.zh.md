# 评价协议

[LSBench](https://github.com/patsnap/LSBench#简体中文) · [English](evaluation-protocol.md) | **简体中文**

LSBench 通过核心生命科学任务评价 AI 模型与 Agent 的专业交付。各任务具有各自的评价对象、匹配标准与指标。

## 任务与指标

| 任务 | 评价对象 | 指标 |
|---|---|---|
| [Chemical NER](../chemical-ner/README.zh.md) | 权利要求或说明书中的化学名称与分子结构集合 | 名称集合与结构集合精确率、召回率、F1，分别报告 |
| [Chemical OCSR](../chemical-ocsr/README.zh.md) | 图像结构识别，或单页 PDF 区域定位与结构识别 | 图像：InChIKey 识别 P/R/F1；PDF：Layout IoU 匹配与 OCSR InChIKey 识别分别报告 P/R/F1 |
| [SAR](../sar/README.zh.md) | 已披露活性记录及其与结构、实验和来源位置的关联 | 记录对齐后的字段级与记录组精确率、召回率、F1 |
| [LCA](../lca/README.zh.md) | 从专利号获取候选证据，或从药物代号追溯专利与候选分子 | 专利相关性、已知目标结构命中与证据支持；两种输入模式分别报告 |
| [LS Research](../ls-research/README.zh.md) | 包含来源引用的完整研究回答或报告 | 要点覆盖、事实质量与引用支持 |

Chemical NER 评价权利要求或说明书文本。Chemical OCSR 包含图像识别与单页 PDF 的 Layout＋OCSR 两种模式，PDF 的定位和识别结果分别报告。SAR 评价已披露实验记录。LCA 评价候选识别与基于证据的追溯。LS Research 评价完整回答及其支持来源。

## 匹配与证据

- **Chemical NER：**在给定的权利要求或说明书文本范围内评价名称集合和分子结构集合；同一项的重复出现只计一次，名称与结构分别报告。
- **Chemical OCSR：**图像模式按完整 InChIKey 评价结构识别。PDF 模式按 IoU 对化学结构区域框一对一匹配，并按完整 InChIKey 评价分子身份；Layout 与 OCSR 的精确率、召回率、F1 分别报告。不同位置的相同结构保留各自出现次数。
- **SAR：**按化合物与实验条件对齐预测记录与参考记录。字段评价包括化合物编号、实验指标、数值、单位、实验模型、靶点、方法、结构身份、活性来源位置与结构来源位置。通过记录对齐与联合字段核验保留化合物、实验、测量与证据之间的对应关系。
- **LCA：**按适用输入模式评价专利相关性、完整结构身份、活性证据、来源位置与证据等级。证据等级表示验证深度。已知目标命中指标适用于具有已披露参考结构的子集，不代表完整召回。
- **LS Research：**评价回答是否回应研究问题、涵盖必要发现、准确陈述事实，并引用支持相应事实陈述的来源。

## 同条件评价

比较采用相同的任务材料、证据范围、信息截止时点、可用工具与执行预算。模型与 Agent 提交在各自组别内报告。报告明确被评系统、任务与参考版本、匹配或评分量规标准，以及适用的运行条件。

各任务分别报告评价单位、指标、覆盖范围与局限。专利、页面、图像、结构、记录与问题的计数保持区分。NER 的名称与结构分别报告；LCA 的专利号模式与药物代号模式分别报告。LSBench 不将不同任务单位合成为单一总分。
