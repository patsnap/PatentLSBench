# SAR

[LSBench](https://github.com/patsnap/LSBench#简体中文) · [English](README.md) | **简体中文** · [评价协议](../docs/evaluation-protocol.zh.md)

SAR 评价从小分子专利中抽取已披露结构—活性证据的能力。

## 输入

包含化合物结构、实验描述与活性测量结果的原始专利材料。

## 输出

关联化合物结构、实验条件与证据位置的活性记录。

## 评价

在同一专利内，按化合物与实验上下文对记录进行一对一匹配，计算字段级和联合字段记录级的精确率（Precision）、召回率（Recall）与 F1，并按跨专利计数汇总。化合物—实验—测量之间的关联正确性通过记录对齐与字段核验共同评价。

| 字段 | 评价重点 |
|---|---|
| 化合物编号 | 与专利所述化合物的对应关系 |
| 实验指标 | 所报告测量指标的身份 |
| 数值 | 所报告结果的含义，包括限定符与范围 |
| 单位 | 测量结果所对应的单位与量纲 |
| 实验模型 | 实验系统或背景条件 |
| 靶点 | 与实验关联的靶点 |
| 方法 | 所报告的实验方法 |
| 结构身份 | 完整分子身份 |
| 活性来源位置 | 活性证据的可追溯性 |
| 结构来源位置 | 结构证据的可追溯性 |

结合原实验上下文核验语义等价表述与有效的单位换算，保持数值、限定符、范围与实验条件的含义一致。

分别报告以下层级：

- **SAR 字段：**化合物编号、实验指标、数值、单位、实验模型、靶点与方法。
- **结构—活性记录：**SAR 字段与化学身份的联合结果。
- **端到端记录：**结构—活性记录与活性、结构来源位置的联合结果。

记录组匹配要求同一对齐记录中的相应字段均符合判定标准。字段级结果与记录组结果分别报告。
