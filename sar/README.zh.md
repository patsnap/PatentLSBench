# SAR

[LSBench](https://github.com/patsnap/LSBench#简体中文) · [English](README.md) | **简体中文** · [评价协议](../docs/evaluation-protocol.zh.md)

SAR 评价从完整小分子专利中抽取已披露结构—活性证据的能力。

## 输入

包含化合物结构、实验描述与活性测量结果的完整小分子专利。

## 输出

关联化合物结构、实验条件与证据位置的活性记录。

## 评价

按化合物与实验对齐记录，评价记录完整性、字段级精确率（Precision）、召回率（Recall）与 F1，以及化合物—实验—测量关系的正确性。

| 字段 | 评价重点 |
|---|---|
| 化合物编号 | 与专利所述化合物的对应关系 |
| 实验指标 | 所报告测量指标的身份 |
| 数值 | 对所报告结果的准确抽取 |
| 单位 | 测量结果所对应单位的正确性 |
| 实验模型 | 实验系统或背景条件 |
| 靶点 | 与实验关联的靶点 |
| 方法 | 所报告的实验方法 |
| 结构身份 | 完整分子身份 |
| 活性来源位置 | 活性证据的可追溯性 |
| 结构来源位置 | 结构证据的可追溯性 |

字段准确性、关系覆盖与整篇专利完整性分别报告。
