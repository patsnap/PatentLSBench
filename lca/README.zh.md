# LCA

[PatentLSBench](https://github.com/patsnap/PatentLSBench/blob/main/README.zh.md) · [English](README.md) | **简体中文**

LCA 评价基于证据识别候选分子，以及在药物代号、专利与结构之间进行追溯的能力。

## 输入与输出

| 输入模式 | 输入 | 输出 |
|---|---|---|
| 专利号 | 单个专利号 | 候选分子及其结构、已披露活性、来源位置与证据等级 |
| 药物代号 | 单个药物代号 | 相关专利与候选分子，以及支持药物—专利—结构关系的证据 |

## 评价

- 专利相关性与对象身份。
- 对已披露参考目标结构的样本评价完整结构匹配。
- 活性结论、来源位置与证据等级的支持依据。
- 候选证据的完整性，以及所要求对象之间的可追溯性。

两种输入模式分别报告成绩。已知目标结构命中结果明确其适用子集，不代表专利或候选分子的完整召回。证据等级表示验证深度；证据支持程度相同的候选不要求人为指定唯一优胜者。
