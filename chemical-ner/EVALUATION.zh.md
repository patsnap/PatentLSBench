# Chemical NER Bench 评价

[数据集](README.zh.md) · [English](EVALUATION.md) | **简体中文**

v1.2.2 提供完整、独立的 `claim` 和 `description` 输入及实体级评测参考答案。

本发布提供参考数据与报告要求，尚未提供统一执行评分器或冻结默认匹配 profile。只有匹配、参考纳入及聚合规则相同的结果才可直接比较。

标注覆盖与结构表示限制见[参考说明](REFERENCE_NOTES.zh.md)。空参考列表不代表已核验的无化学实体真负例。

## 输入与参考字段

模型请求包含 `record_id`、`publication_number`、`language`、`section` 和 `text`。`ground_truth` 单独用于评价。

记录的 `text` 为完整章节 HTML。实体边界对应该字符串中的 Unicode 码点，从 0 开始、使用左闭右开的 `[start, end)` 区间，HTML 标签字符也计入。实体参考列表为空的章节是有效记录。

每个参考实体包含名称（`text`）、化学实体类别（`label`）、边界（`start`、`end`）、结构标识（`smiles`、`inchikey`）和名称表达类型（`mention_form`）。`ChemicalCompound` 与 `compound` 都表示化学实体。结构字段的空字符串表示无对应结构参考，名称表达类型的 null 表示无类型信息。

## 实体识别与结构归一化

| 评价 | 参考字段 | 报告范围 |
| --- | --- | --- |
| 实体识别 | 名称、类别及边界 | 明确匹配单位，以及命中须满足的字段条件 |
| 结构归一化 | 适用的非空 `smiles` 或 `inchikey` 值 | 明确标识符字段、纳入条件、规范化规则及参考覆盖范围 |

实体识别与结构归一化的 Precision、Recall、F1 分别报告。参考列表支持实体提及比对。若进行去重，或按章节聚合名称／结构，须在评价规则中明确说明；数据集的实体提及总数保持独立计数。

InChIKey 比较使用完整标识符字符串。明确格式不符合条件或缺失的参考，以及纳入范围之外预测的处理方式。缺少适用结构参考的实体仍参与相应的实体识别评价。

## 计数与聚合

按已声明的匹配单位，报告命中数（TP）、预测数和参考数。`Precision = TP / 预测数`，`Recall = TP / 参考数`，`F1 = 2 × TP /（预测数 + 参考数）`。

权利要求与说明书结果分别呈现。若给出合并结果，须明确聚合方法、零分母及失败请求的处理规则。采用 Micro 聚合时，先累加对应计数，再计算比率。

报告明确数据版本、split、参评记录 ID、预测格式、匹配条件、规范化、去重、参考纳入及聚合规则。本数据集含 6,334 次实体提及；提及数、名称数和结构数分别计数。
